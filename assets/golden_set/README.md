# Golden Set — complete-card visual references

This directory contains complete composed flashcards: illustration, teaching labels, and any connectors. Use these whole cards to compare the finished product's composition, label hierarchy, whitespace, and visual consistency.

The files under assets/grade_style_references serve a different purpose: primary_art.png, middle_art.png, and high_art.png are illustration-only images for Stage 07 generation. Their same-band primary.png, middle.png, and high.png files are complete single-word cards. Neither set substitutes for these multiword Golden Set examples.

## Use

- Compare the complete card composition, age-appropriate scene treatment, label hierarchy and connector salience.
- Do not use text read from any Golden Set image as curriculum truth. English, pronunciation, and Chinese gloss must come from the current authoritative source.
- The Grade 5 and middle-school samples are visual references only; their source decks have not completed full editorial review.
- Platform adapters may add tested references, but cannot use a reference image to override curriculum facts.
